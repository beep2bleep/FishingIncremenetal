# Store Assets Pack: Data Breach Inc.

Store copy for itch.io and Steam uploads. Text only; art is intentionally not bundled.

## What this pack includes
- `common/`: positioning, headlines, summaries, master long copy, tags, graphic copy notes
- `steam/`: Steam short description, About This Game copy, BBCode version, capsule copy guide
- `itchio/`: itch.io short description, long page copy, page layout plan

## Product positioning used
Data Breach Inc. is an arcade incremental breach game: pilot a rig through hostile corporate infrastructure, mine blocks, crack daemon cores, bank resources, and unlock connected side operations like Red Sky Defense and Deepcore.

## Notes
- Keep all copy aligned with the current build before publishing.
- The copy avoids promising final feature counts, release dates, multiplayer, or online services beyond leaderboards.
- The art direction assumes you already have finished capsules/screenshots/trailer material.
