itch.io Page Layout Plan

Top of page:
- Strong short hook (1 sentence)
- 1 hero screenshot or short gameplay GIF showing the drill rig in motion

Immediately below:
- 3 to 6 bullet features

Middle section:
- Core loop explanation (5-step sequence)
- 3 to 5 additional screenshots focused on drilling, cargo flow, depth progression, and upgrades

Lower section:
- Controls
- Session length expectations
- Current status and update notes

Footer:
- Contact / community links

Screenshot shot list:
1) Live drilling scene with full HUD visible
2) Cargo almost full / risk-reward return moment
3) Deeper depth with richer material palette
4) Upgrade screen with Mining upgrades visible
5) Run summary screen showing payout, XP, and unlocked depth
