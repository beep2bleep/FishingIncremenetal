itch.io page checklist — Red Sky Defense
Source: itch.io creator quality + design docs

Core elements
- Cover image and readable Red Sky Defense title
- Short summary at top of page
- Long description with sections
- Real gameplay screenshots (no misleading frames)
- Accurate genre/tags/platforms

Recommended order
1) Hook line
2) Feature bullets
3) Media (GIF/trailer + screenshots)
4) Loop explanation
5) Controls / session style
6) Build notes or status

Image guidance
- Prefer 1920x1080 screenshots
- Keep important text/UI inside a safe center region

Quality bar
- No lorem ipsum
- Descriptions match the current build
- Do not go public until cover, screenshots, and files are ready
