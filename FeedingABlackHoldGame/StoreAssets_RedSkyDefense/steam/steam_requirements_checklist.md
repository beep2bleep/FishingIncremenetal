Steam store submission checklist — Red Sky Defense
Source: Steamworks docs (store assets + written description)

Required store graphic assets (standard sizes):
- Header capsule: 920 x 430
- Small capsule: 462 x 174
- Main capsule: 1232 x 706
- Vertical capsule: 748 x 896

Required Steam library assets:
- Library capsule: 600 x 900
- Library header: 920 x 430
- Library hero: 3840 x 1240
- Library logo: transparent PNG; width ≥1280 and/or height ≥720

Library notes:
- Library hero cannot include text
- Library logo should be logo/title only on transparency

Written fields:
- Short description
- About This Game
- Supported languages
- Screenshots aligned with copy

Suggested screenshot set (6–10):
1) Mid-wave combat with base and enemies readable
2) Heavy wave or elite moment showing pressure
3) Between-wave offer / upgrade choice screen
4) Meta upgrade tree with Red Sky–specific nodes visible
5) Nuke or big area tool moment if featured in your build
6) Late-run UI showing scaled difficulty or economy
7) Any unique enemy or biome read that sells the mode

Store QA:
- Short description says wave defense + incremental clearly
- First screenshots are gameplay, not menus only
- Capsules read as Red Sky Defense at thumbnail size
