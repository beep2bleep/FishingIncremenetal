# Store Assets Pack: Red Sky Defense

Store copy and checklists for itch.io and Steam (text only; no bundled graphics).

## What this pack includes
- `common/`: positioning, headlines, summaries, master long copy, tags, graphic size manifest
- `steam/`: Steam short/long copy, capsule direction, submission checklist
- `itchio/`: itch page copy, layout plan, checklist

## Product positioning used
Red Sky Defense is a wave-defense incremental: hold a base against escalating waves, spend scrap between rounds, roll and choose upgrade offers, and grow through a meta upgrade tree (hull, guns, nukes, towers, drones, tentacles, and more).

## Graphic templates
This pack does not include SVG/PNG placeholders. Use blank size templates from:
- `res://StoreAssets/templates/` (Vanguard pack), or
- `res://StoreAssets_MiningMode/templates/` (Deepcore pack)

Dimensions are listed in `common/asset_manifest.txt`.
