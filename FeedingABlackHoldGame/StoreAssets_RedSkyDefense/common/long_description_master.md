# Red Sky Defense

Hold the base. Bank the scrap. Survive what comes next.

Red Sky Defense is a **wave-defense incremental**: you fight escalating waves, earn scrap from kills and wave clears, and spend between rounds on upgrade offers and long-term meta nodes. The run is about staying ahead of scaling enemies while your build specializes—more damage, better survivability, stronger area tools, and unlocks that open new layers of defense.

## Why play
- Clear loop: waves → payout → choices → stronger next attempt
- Offer pacing between waves keeps builds different run to run
- Meta tree supports many playstyles (core gunplay, nukes, deployables, and more)
- Built for repeat runs and incremental optimization

## Core loop
1. Enter a wave set; enemies approach and pressure the base.
2. Fight with your current stats, pickups, and tools (including nukes when available).
3. Clear or fail; earn scrap and progress markers based on performance.
4. Review between-wave offers: improve damage, defense, economy, or unlock systems.
5. Spend meta currency on permanent tree upgrades for the next campaigns.

## Gameplay systems (keep copy aligned with the build)
- Base health and defensive scaling options
- Active combat with projectile pressure and readable feedback
- Nukes and other high-impact tools where implemented
- Between-wave offer tiers and player choices
- Meta upgrade branches (including deployable-style unlocks when enabled)

## Session style
Sessions work as “one more wave” bursts or longer pushes when chasing milestones. Progression is meant to feel steady: each upgrade should answer a problem the last wave exposed.
