itch.io page checklist — Reel Into Darkness
Source: itch.io creator quality + design docs

Core elements
- Cover communicates tone (dark water, readable title)
- Short summary
- Long description with sections
- Honest screenshots
- Tags/genre/platforms accurate to the build

Order
1) Hook + tone warning if appropriate
2) Bullets
3) Media
4) Features + loop
5) Controls/status

Quality
- No placeholder copy
- Atmosphere claims match actual scare level
- Page stays draft until media + files ready
