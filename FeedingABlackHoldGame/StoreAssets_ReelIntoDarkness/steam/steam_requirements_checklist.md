Steam store submission checklist — Reel Into Darkness
Source: Steamworks docs (store assets + written description)

Required store graphic assets (standard sizes):
- Header capsule: 920 x 430
- Small capsule: 462 x 174
- Main capsule: 1232 x 706
- Vertical capsule: 748 x 896

Required Steam library assets:
- Library capsule: 600 x 900
- Library header: 920 x 430
- Library hero: 3840 x 1240
- Library logo: transparent PNG; width ≥1280 and/or height ≥720

Library notes:
- Library hero cannot include text
- Library logo should be logo/title only on transparency

Written fields:
- Short description
- About This Game
- Supported languages
- Screenshots aligned with copy

Suggested screenshot set (6–10):
1) Fishing view at night with water and UI readable
2) Fish on the line / tension moment
3) Inventory or sell screen showing economy
4) Upgrade tree with Reel-specific nodes
5) Deeper depth or rare fish encounter
6) Calm atmospheric wide shot that sells tone
7) Late progression depth or high-value catch

Store QA:
- Short description states fishing + incremental clearly
- Screenshots show real gameplay, not mockups
- Tone in copy matches actual scare level in-game
