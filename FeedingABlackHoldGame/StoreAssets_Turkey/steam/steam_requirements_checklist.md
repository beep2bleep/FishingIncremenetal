Steam store submission checklist — Turkey
Source: Steamworks docs (store assets + written description)

Required store graphic assets (standard sizes):
- Header capsule: 920 x 430
- Small capsule: 462 x 174
- Main capsule: 1232 x 706
- Vertical capsule: 748 x 896

Required Steam library assets:
- Library capsule: 600 x 900
- Library header: 920 x 430
- Library hero: 3840 x 1240
- Library logo: transparent PNG; width ≥1280 and/or height ≥720

Library notes:
- Library hero cannot include text
- Library logo should be logo/title only on transparency

Written fields:
- Short description
- About This Game
- Supported languages
- Screenshots aligned with copy

Suggested screenshot set (6–10):
1) Lane view at release with ball and pins readable
2) Pin scatter / impact moment
3) Shot setup UI (power, spin, position) if it sells the skill loop
4) Score or frame summary screen
5) Meta / upgrade screen with Turkey-specific options
6) Stylized moment that matches your CRT or presentation layer if featured
7) Clean strike or challenging spare setup

Store QA:
- Short description communicates arcade lane + physics + scoring
- First shots are gameplay, not empty menus
- Capsules read as Turkey at thumbnail scale
